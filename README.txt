# 我的待辦 PWA 第一版

這是一個可安裝到 iPhone 主畫面的手機待辦 PWA 原型。

## 功能
- 待辦依期限自動排序
- 新增期限、優先等級、提前提醒、備註
- 完成
- 列入下月
- 10 分鐘後提醒
- 4 小時後提醒
- 8 小時後提醒
- 自訂提醒
- 逾期顯示
- 已完成資料保留在瀏覽器本機

## 重要說明
目前這個第一版使用瀏覽器/Service Worker 與本機資料儲存，適合先驗證介面與操作流程。
若要做到「即使 App 沒有開啟、手機鎖定、甚至數小時後仍可靠收到排程 Push 通知」，下一版需要加入雲端 Push/通知服務與後端排程。

## 在 iPhone 使用
1. 將本資料夾部署到 HTTPS 網站。
2. 用 iPhone Safari 開啟。
3. 選「加入主畫面」。
4. 開啟通知權限。
5. 從主畫面的「我的待辦」使用。
